How it works

Four steps. Ten seconds.

From download to done — no installer, no admin rights, no configuration.

Download the .exe

Grab favicon-maker.exe from GitHub. It's about 713 KB — smaller than a photo.

Save anywhere

Desktop, Downloads, a USB stick — wherever. It runs in place without installing anything.

Double-click to run

A small native window opens. Windows may show a SmartScreen prompt the first time — click "More info → Run anyway".

Drop an image → export

Drag your image, pick a background color, hit generate, save the ZIP. Done.
