PDF Compressor. Desktop edition.

A fully offline desktop application for compressing PDF files on Windows, macOS, and Linux. No cloud, no accounts, no uploads — your documents never leave your machine.

✨ Key features

  • 🗜️
    Smart compression Reduces PDF size by up to 80% while preserving text quality.
  • 🔒
    Fully offline No internet connection required. Your files never leave your device.
  • 📚
    Batch processing Compress multiple PDF files at once with a single click.
  • 🎚️
    Three quality modes Low, Medium, and High presets to balance size and quality.
  • 🔍
    Preview before save See original and compressed sizes before overwriting.
  • 🖱️
    Drag & drop Simple drag-and-drop interface for quick workflows.

⬇️ Download & install

All builds are published on GitHub. Choose the installer for your operating system.

  • 🪟 Windows installer .exe · 64-bit · ~12 MB ↗
  • 🍎 macOS package .dmg · Intel & Apple Silicon · ~14 MB ↗
  • 🐧 Linux package .AppImage · .deb · ~13 MB ↗
  • 🐙 Source code Clone or fork from GitHub ↗
System requirements Windows 10 or later, macOS 11 or later, or a modern Linux distribution. 4 GB RAM minimum, 200 MB free disk space. No GPU or internet connection required.
