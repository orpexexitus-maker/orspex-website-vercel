First-run wizard did not preserve branch selection on some Windows locales
On certain regional settings, the default branch selected during first-run setup could reset after restart. Resolved in v1.0.0.
State: Resolved Fixed in: v1.0.0

Journal entry totals could display rounded figures with a specific locale
Under some number-format settings, the journal entry footer briefly showed rounded totals while editing. The final posted values were always correct. Resolved in v1.0.0.
